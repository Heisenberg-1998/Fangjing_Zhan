# 五、为何 β、正常增长率与残差不能确立因果，也不构成预测

1. **β 是假设而非估计**：0.35 是教学情景参数，不是从数据中识别的国别奥肯系数；换一个 β 会得到完全不同的失业路径，因此结果对假设高度敏感。
2. **正常增长率是任意的固定基准**：用 2019 年单年实际增长率充当"正常增长"，把 2019 年的一切特殊因素（基数效应、周期位置）都固化为基准；它不是潜在产出增长率，也不是 NAIRU 意义上的趋势。
3. **恒等式式递推，非行为方程**：Δu = −β(g − g_normal) 是条件性经验关系（工具本身也标注"not an identified causal effect"），不含反馈、滞后、参与率变化、移民、工时调整等渠道；GDP 与失业同期双向影响，存在联立性与遗漏变量偏误。
4. **残差不是检验**：模型−实际残差混合了 β 误设、基准误设、以及 2020–2023 年疫情/供给冲击等模型外因素；残差大小不能证明模型"对"或"错"，更不能证明 GDP 增长"导致"失业变化。
5. **不是预测**：这是对已实现数据的**回溯性情景核算（backward-looking scenario accounting）**，使用事后实际增长率；真正的预测需要事前信息、不确定性区间与结构性假设。中国残差 +1.57 pp 尤其提示：ILO 建模失业率与 GDP 增长在中国的关系受统计口径（调查失业率 vs. 登记失业率、农民工回流）影响，简单奥肯关系不适用。

# 中国、美国、日本 2019–2023 年实际 GDP 增长：均值、CAGR 与复合累计增长

## 数据来源与定义

- **来源**：World Bank WDI 冻结快照（frozen snapshot），`snapshot_sha256 = 94d459365192b40abe87ace9e2486d814c6edf696cc75fe6cae1ecd1c261ae21`

- **单位**：annual %（年百分比）
- **可定位引用**：`https://api.worldbank.org/v2/country/USA;CHN;JPN/indicator/NY.GDP.MKTP.KD.ZG?date=2019:2023&format=json&per_page=1000`

| 2019 | 6.06737806333672 | 2.58382533052225 | -0.308496921143259 |

## 公式

设 $g_t$ 为第 $t$ 年增长率（百分数），$n=5$：

- 算术平均：$\bar g = \frac{1}{n}\sum_{t=1}^{n} g_t$
- 复合累计增长（2018 年末→2023 年末）：$G = \left[\prod_{t=1}^{n}\left(1+\frac{g_t}{100}\right)-1\right]\times 100$
- 五年 CAGR：$\text{CAGR} = \left[\prod_{t=1}^{n}\left(1+\frac{g_t}{100}\right)\right]^{1/n}-1$，以百分数表示
- 朴素求和：$S = \sum_{t=1}^{n} g_t$
- 求和减复合累计：$S - G$（百分点）
- 均值减 CAGR：$\bar g - \text{CAGR}$（百分点）

## 为什么算术平均不等于 CAGR

算术平均是对**增长率本身**取平均，隐含"每年在同一基数上增长"的线性假设；CAGR 则是对**增长后的水平（指数）**取几何平均，反映"每年按同一比例复利增长"的等效速率。由于乘法复合，各年增长率作用在不断变化的基数上，几何平均必然不高于算术平均（AM–GM 不等式），两者之差随增长率波动幅度增大而扩大。本例中波动最大的是日本（−4.28% 到 +3.56%），其均值−CAGR 差为 0.0335 个百分点；中国波动也很大（2.34% 到 8.57%），差为 0.0233 个百分点。注意：当增长率序列含负值时，几何平均的严格 AM–GM 表述需谨慎，但"均值 ≥ CAGR"的方向在此仍成立。

## 为什么年度增长率不能直接相加

年度增长率是**相对各自上一年基数**的百分比，基数逐年变化，因此不可加。若把 5 年增长率直接相加，等于假设每年都相对 2018 年同一基数增长，忽略了复利。正确做法是连乘：$\prod(1+g_t/100)$。以中国为例，朴素求和 25.5271% 比真实复合累计 28.1281% 低 23.0227 个百分点——差异主要来自 2021 年 8.57% 的高增长作用在已被 2019–2020 抬高的基数上，其绝对增量远大于按 2018 年基数计算的增量。美国、日本同样存在这一低估（分别为 10.1051 和 0.6552 个百分点）。

## 说明

以上均为对冻结快照数据的机械算术运算，不构成因果推断；反事实与合成组合亦仅为算术构造。
