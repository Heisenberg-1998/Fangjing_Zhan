# 五、为什么 β、正常增长率与残差不能确立因果，也不能当作预测

1. **β 是假设值**：0.35 是教学情景参数，不是从数据估计的国别系数；真实 Okun 系数随制度、工时调整、参与率变化而变动，且随样本期不同而不同。
2. **正常增长率是机械基准**：用 2019 年单年实际增长率充当"正常增长"，把一次性的疫情前状态当作常态，本身没有潜在产出、NAIRU 或趋势劳动生产率的理论依据；2019 年对日本是负增长，作为"正常"基准尤其任意。
3. **恒等式而非行为方程**：Δu = -β(g − g_n) 是定义式叠加，给定 g 与 β 必然得出 u，残差只度量"模型路径与实际路径的算术偏离"，不识别任何结构性冲击。
4. **反向因果与遗漏变量**：增长与失业同时受需求冲击、财政货币政策、供给冲击（能源、供应链）、移民与参与率变动影响；β 的符号不能排除失业变动影响增长，也不能排除共同驱动因素。
5. **残差不是误差检验**：残差大（如中国 +1.57 pp、日本 −1.15 pp）主要反映基准选择与 β 假设不当、以及 ILO 建模失业率与国内调查口径差异，而非"模型被数据拒绝"的统计推断。

# 六、为何这些玩具计算无法识别最优政策利率，也不能把历史 CPI 变成观测到的预期

1. **Okun 关系是条件性经验关联，非因果**：β=0.4 是用户设定常数，不是估计的国别系数；单期一次性映射忽略了滞后、反馈与政策内生性。正常增长率用 2019–2023 算术均值，包含疫情异常年份，本身不是潜在增长率的估计。
2. **Fisher 方程只是恒等式**：给定 i 与 πᵉ 机械地给出 r；它不含任何行为方程（IS 曲线、菲利普斯曲线、央行损失函数），因此无法判断哪个 i 使产出缺口为零、通胀达目标或福利最大。最优政策利率需要目标函数、约束与冲击结构，这里都没有。
3. **πᵉ 是假设而非观测**：2023 年**已实现**年均 CPI 是事后统计量；预期通胀是前瞻性、不可直接观测的变量，需要调查数据、通胀挂钩债券盈亏平衡率或模型估计。把历史 CPI 当作 πᵉ 只是教学假设，会系统性错估 ex ante 实际利率（且未考虑期限溢价与风险溢价）。
4. **压力情景是机械平移**：+1.25 pp 增长冲击与 +1.50 pp 通胀冲击均为外生设定，未与货币政策反应函数相连，故不能用于评估政策取舍。
5. **名义收益率固定 4.75%**：真实世界中政策利率变动会改变名义收益率，此处固定收益率使"压力"仅作用于通胀端，属简化。
