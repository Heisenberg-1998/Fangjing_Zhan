# MODEL-01

## 模型设定与公式

连续时间 Solow 模型：$y = k^{\alpha}$，$\alpha = 0.5$；人口增长率 $n = 0.01$，技术进步率 $g = 0.02$，折旧率 $\delta = 0.05$，初始有效劳动资本 $k_0 = 1$。所有参数均为用户给定的假设值，未使用任何 WDI 数据或国别估计。

有效劳动稳态条件：$s k^{\alpha} = (n+g+\delta)k$，因此

$$k^* = \left(\frac{s}{n+g+\delta}\right)^{\frac{1}{1-\alpha}},\qquad y^* = (k^*)^{\alpha}$$

其中 $n+g+\delta = 0.01+0.02+0.05 = 0.08$。

**s = 0.20：** $k^* = (0.20/0.08)^{2} = 2.5^2 = 6.25$；$y^* = \sqrt{6.25} = 2.5$

**s = 0.30：** $k^* = (0.30/0.08)^{2} = 3.75^2 = 14.0625$；$y^* = \sqrt{14.0625} = 3.75$

**稳态 y 的增幅：** $(3.75 - 2.5)/2.5 = 1.25/2.5 = 50\%$

**长期人均产出增长率：** 两个情景均为 $g = 2\%$（每年）。在稳态下，人均产出 $Y/L$ 以技术进步率 $g$ 增长，与储蓄率无关。

## 解释：储蓄率提高是否永久提高增长率？

不会。提高储蓄率 $s$ 只提高**稳态水平**（$k^*$ 与 $y^*$ 上升，本例中稳态人均产出提高 50%），并在转型期内带来一段**暂时性**的较快增长；但一旦达到新的稳态，人均产出的长期增长率仍回到 $g = 2\%$。在 Solow 模型中，只有技术进步（$g$）决定长期人均增长，储蓄率只影响水平，不影响长期增长率。

单位说明：$k$、$y$ 为每有效劳动资本与产出（模型单位）；增长率为百分比/年。

## 模型设定与公式

连续时间 Solow 模型（人均有效劳动形式）：

- 生产函数：y = k^α，α = 0.5
- 资本积累：dk/dt = s·k^α − (n + g + δ)·k
- 参数（均为假设值，非估计值）：s = 0.20，n = 0.01，g = 0.02，δ = 0.05，故 n + g + δ = 0.08
- 欧拉离散近似（步长 1 年）：k[t+1] = k[t] + s·k[t]^α − (n+g+δ)·k[t]，k0 = 1

## 计算（精确 Fisher 关系，事前/ex-ante）

**公式与单位**：年化百分比利率，通胀为预期年通胀率（ex-ante）。

- 精确式：r = [(1 + i/100) / (1 + πᵉ/100) − 1] × 100
  = [(1.05)/(1.03) − 1] × 100 = **1.9417%**
- 近似式：r ≈ i − πᵉ = 5% − 3% = **2.0000%**
- 近似减精确：2 − 1.9417475728 = **0.0583 个百分点**

参数均为假设值（i = 5%，πᵉ = 3%），未调用 WDI，也未引用任何国家估计。

## 为什么历史 CPI 年均值不等于这里的预期通胀

1. **时点与信息集不同**：Fisher 关系中的 πᵉ 是决策时点（事前）对**同一期限**未来通胀的预期；历史 CPI 年均增长率是事后已实现值，属于 ex-post，二者只有在预期完全准确时才相等。
2. **平均口径问题**：CPI 年增长率有年均（annual average）、12 月同比、四季度同比等口径，数值可相差明显；"年均"是年内各月价格水平的平均变化，不是对某未来 12 个月的预期。
3. **预期含前瞻信息**：预期通胀反映货币政策、工资合同、能源价格预期等前瞻因素，历史数据只含过去信息（适应性预期只是其中一种粗略代理）。
4. **偏差与噪声**：CPI 存在权重更新、质量调整、季节性与测量误差；历史样本还受一次性冲击（如油价、汇率、税制调整）影响，不宜直接外推。
5. **实际利率需匹配期限与指数**：若用历史 CPI 计算，应明确标注为**事后实际利率（ex-post）**，并说明所用指数与期限；不能把它当作事前实际利率。

因此本答案严格使用"预期"口径（inflation_basis = expected），未用任何历史 CPI 替代。

## 计算说明

**公式（Fisher 精确式）**：实际利率 = ((1 + i/100) / (1 + π/100) − 1) × 100，单位：%（年率）。名义利率 i = 5%，同一期限（1 年）。

**1. 事前（ex-ante）实际利率**——使用**预期**通胀 3%：
((1.05)/(1.03) − 1) × 100 = 1.9417%
（近似式 i − π = 2%，仅作参考，不替代精确值。）

**2. 事后（ex-post）实际利率**——使用**已实现**通胀 6%：
((1.05)/(1.06) − 1) × 100 = −0.9434%
（近似式 = −1%。）

**3. 事后减事前**：
−0.9434 − 1.9417 = −2.8851 个百分点（pp）。
