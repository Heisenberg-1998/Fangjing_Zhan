# 五、为何 β、正常增长率与残差不能确立因果，也不能作为预测验证

1. **β = 0.35 是假设，不是估计**：它没有经过数据拟合、没有标准误、没有识别策略；换一个 β 会得到完全不同的路径。它只是把"增长缺口"线性映射为失业变化的教学装置。
2. **正常增长率是 2019 年单点观测**：2019 年本身受当年冲击影响，用它当基准等于假设"2019 年产出缺口为零"，这是未经检验的假设，不是潜在产出的度量。
3. **恒等式式递推不构成因果识别**：Δu = −β(g − g_n) 是定义性/机械性关系，缺少工具变量、外生冲击或反事实，无法排除反向因果（失业影响增长）与遗漏变量（疫情、财政转移、移民、劳动参与率变化）。
4. **残差不是检验统计量**：模型值与实际值之差混合了 β 误设、基准误设、以及模型遗漏的所有因素；残差小不代表模型正确，残差大也不证伪机制。它没有抽样分布，无法做显著性判断。
5. **样本内拟合 ≠ 预测**：全部参数（含基准）都取自同一 2019–2023 窗口，属于事后拟合；没有样本外检验、没有预测区间，因此不能称为"预测"或"预测验证"。
6. **失业率口径问题**：ILO 建模估计是平滑的模型序列，与各国官方登记/调查失业率口径不同，机械递推的偏差部分来自口径而非经济机制。

# 二、假设性 Solow 教学情景（非估计系数）

- s = 0.23：s/0.08 = 2.875 → k* = 2.875^{1/0.65} ≈ **5.0766**；y* ≈ **1.7658**
- s = 0.28：s/0.08 = 3.5 → k* = 3.5^{1/0.65} ≈ **6.8706**；y* ≈ **1.9632**

**欧拉迭代**：k_{t+1} = k_t + s·k_t^0.35 − 0.08·k_t，恰好 30 步。
