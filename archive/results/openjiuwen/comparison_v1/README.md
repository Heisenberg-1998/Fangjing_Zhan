## 可复现与限制

本目录保存四组可读回答、题目快照、运行ID及日志/提示词哈希。原始日志仍在上级A/B/C/D目录。D沿用先前运行，A/B/C本次并行执行，因此时延受并发和API缓存影响，不是严格时延对照。检索v1与默认v2不同，本轮显式固定v1以匹配D；源代码包装层哈希不同，已核对实际模型输入一致。该40题仍为候选集，只有一次重复；正式结论需完成统一评分并披露测试集反馈。

复跑入口：`scripts/jiuwen_agent.py --group A --retrieval-version v1 --questions evaluation/test/questions.jsonl --language en`，依次替换A为B/C/D。
